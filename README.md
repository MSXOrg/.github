# MSXOrg community defaults

`MSXOrg/.github` is GitHub's special public repository for organization-wide
community defaults. GitHub uses these files when an MSX repository does not
define its own corresponding file. This repository must remain public for the
fallback behavior to work.

The central [MSX documentation](https://msx.no/docs/) is the source for MSX
standards and ways of working.

Shared MSX images and editable artwork are available in the [media](media)
folder.

Pull request authors use the canonical
[MSX PR Format](https://msx.no/docs/Ways-of-Working/PR-Format/) instructions.
This repository provides no local or organization-fallback PR-template files,
following the
[Repository Standard's file policy](https://msx.no/docs/Ways-of-Working/Repository-Standard/#no-pr-template-files).
The format stays in canonical documentation, not repository template files.
